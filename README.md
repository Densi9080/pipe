# Pipe Seam Finder

Набор утилит для подготовки датасета сварных швов из видео, снятого роботом внутри трубы. 
Пайплайн: **нарезка видео → отбор кандидатов → дедупликация → ручная разметка → обучение**.

## Требования

- Python 3.10–3.12
- Зависимости:

```bash
python -m venv .venv      
venv\Scripts\activate         
pip install -r requirements.txt
```
## cut.py — нарезка видео и отбор кандидатов
Читает видео потоково, нарезает кадры с заданным fps, считает эвристику и сохраняет кадры-кандидаты. Работает с одним файлом или папкой.
| Параметр | Описание |
|---|---|
| `--fps` | Кадров в секунду для анализа. |
| `--texture-thresh` | Порог текстурной аномалии. Ниже — больше кандидатов. |
| `--gradient-thresh` | Порог градиентной аномалии. |
| `--blur-size` | Размытие перед анализом (гасит шум камеры). |

## dedup.py — удаление почти одинаковых кадров
Робот ползёт медленно, соседние кадры часто почти идентичны. Скрипт сравнивает гистограммы и пропускает кадры, слишком похожие на предыдущий.

## similarity_to_refs.py — ранжирование по похожести на эталоны
Сравнение исходных кадров с эталономными кадрами, отобранными вручную
